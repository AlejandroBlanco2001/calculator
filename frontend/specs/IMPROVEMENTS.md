# Improvements after first version

After finishing the first version I conducted a manual test and I noticed the following:

- I need that when the user does the operation and has the result, when they add another operator, it carries the result, for example `2+2 -> 4 (press +) -> 4+`
- I need that as the expression gets longer, it should allow some type of horizontal scrolling
- It should have a caret, so I can click and move to that position (or with the keyboard)
- The errors should be red letters, and much smaller than the text used for the numbers
